# Full Stack Lab 01 - Personal Portfolio

## Purpose
A personal portfolio project demonstrating semantic HTML5 structure, custom CSS styling, and responsive layout design using Bootstrap 5.

- [`Hamza.html`](file:///d:/Hamza/Sem%205/Full%20Stack%20Lab/242712-Lab%20Task%2001/Hamza.html): Portfolio webpage built with semantic HTML5 and custom CSS.
- [`BS.html`](file:///d:/Hamza/Sem%205/Full%20Stack%20Lab/242712-Lab%20Task%2001/BS.html): Portfolio webpage built using Bootstrap 5.
- [`Hamza.css`](file:///d:/Hamza/Sem%205/Full%20Stack%20Lab/242712-Lab%20Task%2001/Hamza.css): Custom stylesheet for `Hamza.html`.

## How to Run
Double-click and open either [`Hamza.html`](file:///d:/Hamza/Sem%205/Full%20Stack%20Lab/242712-Lab%20Task%2001/Hamza.html) or [`BS.html`](file:///d:/Hamza/Sem%205/Full%20Stack%20Lab/242712-Lab%20Task%2001/BS.html) in any web browser (Chrome, Edge, Firefox).
